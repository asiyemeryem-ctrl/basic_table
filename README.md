# Merhaba Tablolar!

Basit HTML tablo oluşturma pratik projesi.

## 📋 Proje İçeriği

Bu proje, HTML tablolarıyla metin rengi ekleme gösterir.

```html
<!DOCTYPE html>
<html lang="tr">

<head>
<meta charset="utf-8"/>
<title> basit tablo oluşturmak </title> 
<link rel="stylesheet" href="tablo_gorunum.css">
</head>

<body>
<h1> <font color="#c71585">Merhaba Tablolar!</font></h1>
<table id="t01">
<tr>
<td> <font color=#ff1493>ilk sütun başı</font></td>
<td> <font color=#ff1493>ikinci sütun başı</font> </td>
<td> <font color=#ff1493>üçüncü sütun başı</font> </td>
</tr>
<tr>
<td> <font color=#ffbbff>ilk hücre</font> </td>
<td> <font color=#ffbbff>ikinci hücre</font> </td>
<td> <font color=#ffbbff>üçüncü hücre</font> </td>
</tr>
<tr>
<td> <font color=#ffbbff>dördüncü hücre</font> </td>
<td> <font color=#ffbbff>beşinci hücre</font> </td>
<td> <font color=#ffbbff>altıncı hücre</font> </td>
</tr>
</table>
<font color=#bb8de0 size="4">tablo pratik için web sayfası<a href="http://www.htmldersleri.org/index.php"> PRATİK</a></font><BR>
</body>
</html>
```

## 🎨 Metin Renkleri

- **Başlık**: `#c71585` (Violet Red)
- **Sütun Başları**: `#ff1493` (Deep Pink)
- **Hücreler**: `#ffbbff` (Light Pink)
- **Footer**: `#bb8de0` (Medium Orchid)
